# Телеком Оператор — Учёт (Python / Flask)

Веб-приложение для учёта клиентов, заказов и начислений оператора связи.
Написано на **Python** с использованием фреймворка **Flask**.

## Возможности

- **Клиенты** — база клиентов с договорами, тарифами, статусами
- **Заказы** — заказы из CRM с точками подключения, услугами, платежами
- **Заказы в стройке** — заказы в стадии организации с историей комментариев
- **Фикс. начисления** — начисления по фиксированной базе: план/факт
- **Статистика** — аналитика по клиентам, кварталам, годам и статусам

Каждая вкладка поддерживает:
- Добавление записей через модальное окно
- Редактирование ячеек прямо в таблице (нажмите на любую ячейку)
- Удаление строк
- Поиск по таблице в реальном времени
- Экспорт в CSV с поддержкой кириллицы

## Технологии

- **Python 3.10+** — основной язык
- **Flask 3.x** — веб-фреймворк
- **Supabase REST API** — база данных (тот же Supabase-проект)
- **Tailwind CSS** — стили через CDN (не требует сборки)
- **Jinja2** — серверные шаблоны
- Нет зависимостей от npm, Node.js или JavaScript-фреймворков

## Установка и запуск

### 1. Убедитесь, что Python 3.10+ установлен

```bash
python3 --version
```

### 2. Установите зависимости

```bash
cd python_app
pip install -r requirements.txt
```

Если pip запрещает установку в системный Python:

```bash
pip install --break-system-packages -r requirements.txt
```

### 3. Запустите приложение

```bash
python3 app.py
```

Приложение будет доступно по адресу: **http://localhost:5000**

Приложение автоматически читает переменные `SUPABASE_URL` /
`VITE_SUPABASE_URL` и `SUPABASE_ANON_KEY` / `VITE_SUPABASE_ANON_KEY`
из файла `.env` в корне проекта — дополнительная настройка не нужна.

## Структура файлов

```
python_app/

├── utils.py         # Форматирование дат, валют; генерация CSV
├── requirements.txt # flask
├── README.md
├── static/
│   ├── app.css      # Анимации flash, стили inline-редактирования
│   └── app.js       # Модалки, inline-редактирование, поиск, сортировка
└── templates/
    ├── base.html         # Навигация, flash-сообщения
    ├── customers.html    # Вкладка «Клиенты»
    ├── orders.html       # Вкладка «Заказы»
    ├── construction.html # Вкладка «Заказы в стройке» + панель комментариев

```

## Как работает inline-редактирование

Нажмите на любую ячейку таблицы — она превращается в поле ввода.
Нажмите **Enter** или кликните в другое место — изменение сохраняется
сразу через AJAX-запрос к Supabase. Нажмите **Esc** — отменяет правку.

## База данных

Приложение использует ту же базу данных, что и оригинальный проект.
Все таблицы (`customers`, `orders`, `order_comments`, `fixed_charges`,
`services`, `actions`) уже созданы через миграции в папке
`supabase/migrations/`.
